### Full Description (copy-paste ready)

```
music-cli is a terminal-native creative suite that transforms text prompts into
polished audio/video outputs using MiniMax models. Built during MiniMax Week ×
GCI Cloud, it features a full `mc studio` creative compiler with a director
(M3), asset graph, taste profiler, and health checker.

Key capabilities:
- `mc studio build` — compile a creative brief into audio/video with M3 planning
- `mc studio revise` — partial rebuild with plan-diff for iterative refinement
- `mc studio taste` — learn preferences from YouTube/last.fm/ radio sources
- `mc studio doctor` — health check for the build environment
- GMI Cloud / OpenRouter adapters with polling, retries, and resumable caching
- Decision logging via trace.jsonl for full auditability

Models used: M3 (planning), M2.7 (music generation), H3 (video), Speech 2.8
(text-to-speech), Music 3.0 (music generation).

The entry demonstrates a complete creative pipeline: plan → generate → revise →
rebuild, all from the terminal.
```
